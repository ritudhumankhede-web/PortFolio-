✨ About the Project

This repository contains my personal portfolio website, designed to present my work, technical skills, projects, experience, and contact information in a clean and engaging way.

The website is built from scratch using HTML5, CSS3, and JavaScript — with no frameworks and no build tools required.

The focus is on:

🎨 Clean and modern visual design
📱 Fully responsive layouts
⚡ Lightweight and fast performance
✨ Smooth animations and interactions
🧭 Accessible and intuitive navigation
🌿 A distinctive visual identity

📄 File Overview
index.html

Contains the complete structure of the portfolio, including:

Navigation bar
Hero section
About section
Skills
Projects
Journey / timeline
Resume section
Contact section
Footer

Each section is organized using semantic HTML.

css/style.css

Contains the complete visual design of the website, including:

Design variables
Colors
Typography
Layout
Responsive breakpoints
Animations
Component styling

The main design tokens are located near the top of the file inside :root, making it easy to customize the site's colors and visual style.

js/script.js

Contains all client-side interactions, including:

Mobile menu
Scroll reveal animations
Active navigation links
Back-to-top functionality
Hero interaction effects

No external JavaScript dependencies are required.

💻 Run Locally

No installation or build process is required.

Option 1 — Open directly

Simply open:

index.html


in your browser.

Option 2 — VS Code Live Server

Open the project in Visual Studio Code, install the Live Server extension, and launch the site using Open with Live Server.

Option 3 — Python HTTP Server

From the project directory:

python3 -m http.server


Then open:

http://localhost:8000

The site includes support for users who prefer reduced motion through:

This helps reduce unnecessary animations while maintaining the core functionality of the website.
